# CoolMsg_JAVA

Java Swing 기반 **클라이언트–서버 구조 사내 메신저**입니다.
수신자가 접속해 있지 않아도 메시지를 보낼 수 있고, 수신자가 나중에 접속하면 저장된 메시지를 받아 볼 수 있습니다(저장 후 전달, Store-and-Forward).

## 주요 기능 (예정)

- 서버를 통한 1:1 메시지 송수신
- 오프라인 사용자에게 보낸 메시지 저장 및 접속 시 전달
- Swing 기반 클라이언트 GUI
