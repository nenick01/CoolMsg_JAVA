## 1. 요구사항 ID 규칙

| 접두어 | 의미 |
|---|---|
| `REQ-F-xxx` | 기능 요구사항 (Functional) |
| `REQ-N-xxx` | 비기능 요구사항 (Non-functional: 성능, 안정성, 사용성 등) |

- **우선순위**: 상(필수) / 중(가능하면 구현) / 하(추가 기능)
- **상태**: 미착수 / 진행중 / 완료 / 보류

## 5. 사용 시나리오

### 시나리오 1: 오프라인 사용자에게 메시지 보내기
1. 사용자 A가 클라이언트로 서버에 접속한다.
2. A가 접속하지 않은 사용자 B에게 메시지를 보낸다.
3. 서버는 B가 오프라인이므로 메시지를 저장한다.
4. A가 프로그램을 종료한다.
5. 나중에 B가 접속하면 서버가 저장된 메시지를 B에게 전달한다.
6. B의 화면에 A가 보낸 메시지가 표시된다.
